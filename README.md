# Cliff-code

A categorized home page for browsing this repository's HTML and CSS learning work.

## Start here

Open [`index.html`](index.html) for the project hub, or [`projects/index.html`](projects/index.html) for the category directory.

## Categories

- [Forms & inputs](projects/forms/index.html)
- [Layouts & components](projects/layouts/index.html)
- [Web pages](projects/websites/index.html)
- [HTML basics](projects/html-basics/index.html)
- [CSS resources](projects/css/index.html)

## Organization approach

The category pages link to the original files in the repository root. Files have not been moved or renamed, so existing relative links to CSS, JavaScript, and images are preserved. When turning an exercise into a standalone project later, move its HTML and its dependencies together and update relative paths at the same time.
